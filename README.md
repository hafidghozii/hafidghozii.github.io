## Media
All supplied photos/videos are bundled under `assets/images`, `assets/posters`, and `assets/videos`.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Enable GitHub Pages from repository settings.
4. Select the branch/folder containing `index.html`.

No Node.js build step is required.

## Replace the CV
Put your final PDF here:

`assets/CV_Hafid_Ghozi.pdf`

Keep the filename unchanged and the portfolio's **LEBENSLAUF ÖFFNEN** button will automatically use it.
